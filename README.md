# About
Данный проект является `LSTM + CNN` реализацией для генерирования подписей к изображениям:
+ `Attention`;
+ Все нужные архитектуры были реализованы только средствами `PyTorch`;
+ Был реализован `beam search` алгоритм;
+ `ClearML` поддержка;
+ В рамках экспериментов также были протестированы результирующие распределения разных энкодеров, а также время их работы;
+ Подсчёт метрик: `BLEU`, `METEOR`;
+ Объёмная конфигурация через `yaml`;
+ `Training` полностью готов, модель возможно обучать (пока скудно, `BLEU-4: ~0.11`);
+ ~~и всё таки стоило использовать трансформеры~~

## Installation
```sh
git clone https://github.com/haritonn/caption_gen
cd caption_gen
uv sync
```

## Launch
```sh
uv run train.py
```
